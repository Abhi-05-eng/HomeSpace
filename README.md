# 🏡 HomeSpace

HomeSpace is a full-stack Airbnb-inspired web application where users can browse, book, and manage rental properties securely. It includes OTP email verification, online payments, and a host dashboard.

## 🚀 Live Demo

🔗 https://YOUR-RENDER-URL.onrender.com

## ✨ Features

- User Authentication (Signup/Login)
- OTP Email Verification (Brevo)
- Browse & Search Properties
- Filter & Sort Listings
- Add to Favorites
- Book Properties
- Razorpay Payment Integration
- Booking Management
- Reviews & Ratings
- Host Dashboard

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Tailwind CSS, EJS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** Express Session, bcrypt
- **Payment:** Razorpay
- **Email:** Brevo API
- **Deployment:** Render

## ⚙️ Installation

```bash
git clone https://github.com/Abhi-05-eng/HomeSpace.git
cd HomeSpace
npm install
npm start
```

Create a `.env` file and add your required environment variables.
